# HR Analytics & Employee Performance Dashboard

> An interactive and advanced Power BI dashboard designed to analyze human resources data, employee performance metrics, and departmental distribution.

---

## 📊 Project Overview
This project provides deep analytical insights into employee performance, compensation structures, and departmental allocations. It features dynamic manager-level filtering, allowing team leads to track and review their respective team metrics efficiently.

## 🛠️ Key Features & Metrics
* **Manager View Slicer:** Interactive top navigation to filter and isolate data for specific managers (`Carla`, `Cynthia`, `Fred`, `Ian`, `Ram`).
* **KPI Cards:** Quick-glance summary cards displaying Total Salary, Average Age, Total Employees, Highest Salary, Average Salary, and Minimum Salary.
* **Departmental Analysis:** Comparative visualization of employee headcount and total salary expenditure across various departments (Website, Procurement, Sales, Finance, HR).
* **Performance Timeline:** Line chart tracking the average employee ratings over the course of the year.
* **Demographics Breakdown:** Donut chart illustrating the employee distribution by gender type.

---

## 💻 Tools & Technologies Used
* **Power BI Desktop:** For data modeling, visualization, and dashboard creation.
* **DAX (Data Analysis Expressions):** For custom calculated measures and metrics.
* **Microsoft Excel:** As the primary data source.
* **Fluent 2 Theme:** For clean, modern UI and consistent color styling.
